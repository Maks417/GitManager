History-first Git for the desktop

Search the commit graph across every branch, review inline or side-by-side diffs, resolve conflicts in a 3-way merge editor, and clone from GitHub, GitLab or Bitbucket.

Free and open source (MIT) · Latest release · Windows, macOS, Linux

The commit graph across all branches. Selecting a commit shows its files and diff in the inspector.

Built around history

Opening a repository lands on the graph. Everything else — changes, branches, conflicts — is one step away, and the interface stays quiet so history and diffs lead.

Commit graph

Large histories stay fast. Filter to one branch, jump to a branch tip, or reveal a commit far down the list.

Diffs with syntax colors

Monaco-powered diffs, inline or side by side, colored for the file's language.

Branches & sync

Create and switch branches, merge, rebase, fetch, pull and push, with ahead/behind at a glance.

Host accounts

Link GitHub, GitLab (including self-managed) or Bitbucket to browse your repositories. Tokens live in OS secure storage.

Clone & create

Clone over HTTPS or SSH with progress and cancel, or start a new repository with its first commit.

Keyboard-friendly

Move between panes with F6, walk commits and files with the arrow keys, and resize any divider from the keyboard.

Search history in plain words

fix loginCommits whose message contains the text, ignoring case
author:AdaCommits by that author
3f2c1abThat commit
branch:feature/*The history of every branch the pattern matches
branch:main fixA branch filter combined with a message search

Download

The latest release for every platform. Once installed, Git Manager updates itself from GitHub Releases.

Windows

Windows 10 and 11

  • Installer for x64 .exe
  • Installer for Arm64 .exe

The installer isn't code-signed yet. If SmartScreen appears, choose More info → Run anyway.

macOS

Apple silicon (M1 and later)

  • Disk image .dmg
  • App archive .zip

The app isn't notarized yet. Open it the first time with right-click → Open, or run xattr -cr "/Applications/Git Manager.app".

Linux

x64 — Ubuntu, Debian and others

  • AppImage any distribution
  • Debian package .deb

Make the AppImage executable with chmod +x, or install the package with sudo apt install ./Git-Manager-*.deb.

Git Manager uses the Git already installed on your computer. If it can't find Git, it points you to git-scm.com.
