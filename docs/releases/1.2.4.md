# Git Manager 1.2.4

This release makes Git Manager smaller to download and to install. The app itself is unchanged.

## Improvements

- **Smaller downloads:** Windows installers are about 21 MB smaller (x64 134 → 113 MB, arm64 128 → 107 MB). The app's code ships as compact bundles; the font files carry only the format the app uses.
- **Less disk space on Windows:** on NTFS drives the installer compresses the installed files with Windows' own file compression, so the installed app takes about 160 MB instead of 390 MB. On network drives or other file systems the files are installed uncompressed, as before. The installer writes `resources\compression.log` next to the app.
- **Third-party notices:** the licenses of the bundled libraries and fonts are included with the app in `resources/THIRD-PARTY-NOTICES.txt`.
